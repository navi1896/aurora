# Carpeta de video externo del menú principal (CabinaMenu)

Coloca aquí los archivos convertidos a `.ogv` (Ogg Theora):
- `cabina_menu_intro.ogv` (opcional, intro única)
- `cabina_menu_loop.ogv` (loop continuo del menú)

Usa `tools/import_menu_external_video.ps1` para convertir `.mp4`, `.mov` o `.webm` con los flags compatibles de Godot.
