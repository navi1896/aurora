The recipe downloads the BtbN asset, verifies the archive hash, extracts it
into a constrained local directory, verifies both executable hashes and the
license hash, then checks version, license, configuration and capabilities.
It does not install software or change the user or machine PATH.


Configuration and license
-------------------------
The exact version, build configuration and license output from the distributed
executable is included in:

  BUILD_CONFIGURATION.txt

Important properties observed in the validated executable:

  --enable-version3
  --enable-libtheora
  --enable-libvorbis
  --disable-libx264
  --disable-libx265
  --disable-libfdk-aac

The configuration does not contain --enable-gpl or --enable-nonfree. The
complete GNU LGPL version 3 text supplied by the BtbN asset is included in:

  LICENSE.txt

FFmpeg and the selected build enable compatible third-party components beyond
Theora and Vorbis. The full reported configuration and a technical inventory
are included in BUILD_CONFIGURATION.txt and EXTERNAL_LIBRARIES.txt. That
inventory records what the executable reports; it is not a legal opinion or a
substitute for reviewing the corresponding upstream notices before publishing
in another jurisdiction.


Runtime files and dependencies
------------------------------
Only ffmpeg.exe and ffprobe.exe are copied into tools/ffmpeg/bin/. No FFmpeg
DLL, ffplay.exe, documentation bundle, presets or mutable upstream ZIP are
included in Aurora's runtime directory.

The audited Windows import-table inventory is included in:
  RUNTIME_DEPENDENCIES.txt

Those imports are Windows system libraries and API-set contracts. Aurora does
not redistribute them.
