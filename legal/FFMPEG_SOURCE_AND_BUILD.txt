FFMPEG 6.1.6 — SOURCE AND BUILD INFORMATION
=============================================

Bundled programs
----------------
Aurora 1.0.0 includes these separate, replaceable Windows x86_64 command-line
programs:

  tools/ffmpeg/bin/ffmpeg.exe
  SHA-256:
  a395c847b0f070012c0c0f7076f098ad11dd85754a8eecc9c59b0c10004bdd99

  tools/ffmpeg/bin/ffprobe.exe
  SHA-256:
  fe7f73bbe528291779020e4272de2a5ef6bfb85a7ce475358c14cea2ca0c50eb

Version: FFmpeg 6.1.6
Compiler: GCC 16.1.0 from w64devkit 2.8.0
Build date: 2026-07-28
License reported by the executables: GNU LGPL version 2.1 or later
Source modifications by Aurora Project: none

The programs are statically linked internally and do not require FFmpeg DLL
files. Their import tables contain only Windows system libraries:
bcrypt.dll, KERNEL32.dll, msvcrt.dll and SHELL32.dll.

Aurora launches FFmpeg as a separate process. FFmpeg is not linked into
Aurora.exe, is not renamed, and can be replaced by the recipient with another
compatible build that supplies the capabilities required by the editor.

Build recipe and configuration
------------------------------
The complete PowerShell build recipe is included in:

  source/build_ffmpeg_minimal.ps1
  SHA-256:
  2b0de8c20fdfc38cf48e20a9c3d5d91bd2323dc676c298cb00805fca0d4c3cce

Its exact Bash build stage is included in:

  source/build-all.sh
  SHA-256:
  52929717a79175f6909d463c50da8c65b3622f79020e956273fd6c2992cc4b88

It downloads sources by fixed HTTPS URLs, verifies every SHA-256, verifies the
FFmpeg detached signature, prepares an isolated portable toolchain, builds the
three Xiph libraries statically and compiles FFmpeg without modifying source.
It does not install software or change the user or machine PATH.

The exact configuration reported by the distributed executable, together
with its version and license report, is included in:

  BUILD_CONFIGURATION.txt

Important configuration properties:

  --enable-static
  --disable-shared
  --disable-autodetect
  --disable-everything
  --disable-network
  --enable-libtheora
  --enable-libvorbis

The configuration does not use --enable-gpl, --enable-nonfree or
--enable-version3. It enables only the demuxers, decoders, filters, protocols
and Ogg encoders required for Aurora's documented import and validation flow.

These are the exact recipe files preserved by the validated build that
produced the distributed executables. They recreate the same source selection,
compiler version and sanitized configure options. A byte-for-byte identical
executable is not promised on a different host; functional equivalence and
source correspondence are the goals.
