FFMPEG 6.1.6 — EXTERNAL LIBRARIES AND REQUIRED NOTICES
=======================================================

Scope
-----
Aurora's Windows package contains a purpose-built FFmpeg command-line program.
The build uses FFmpeg's native demuxers and decoders, plus exactly these three
external Xiph libraries:

- libogg 1.3.6
- libvorbis 1.3.7
- libtheora 1.2.0

No component enabled with --enable-gpl or --enable-nonfree is present. The
complete configuration printed by the bundled executable is recorded in
BUILD_CONFIGURATION.txt. The exact source archives and reproducible build
recipe accompany the binary under licenses/FFmpeg/source/.

Toolchain and operating-system integration
------------------------------------------
The executable is built with the portable MinGW-w64/GCC toolchain contained in
w64devkit. The GCC Runtime Library Exception permits eligible GCC runtime code
to be linked into the resulting program without changing FFmpeg's license.
The exact toolchain version is recorded in SOURCE_AND_BUILD.txt.
The complete MinGW-w64 runtime notices required for binary distribution are
included in licenses/FFmpeg/MINGW_RUNTIME_LICENSES.txt. The GCC Runtime
Library Exception is included in licenses/FFmpeg/GCC_RUNTIME_EXCEPTION.txt.

Windows system libraries are provided by the operating system and are not
redistributed by Aurora. The final package must not contain FFmpeg DLL files;
ffmpeg.exe and ffprobe.exe are separate, replaceable command-line programs.
